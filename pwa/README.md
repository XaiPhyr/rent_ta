# Frontend Application (Vite + Vue.js)

This repository contains a frontend web application built with **Vue.js** and **Vite**, providing a fast development environment and optimized production builds.

---

## 🚀 Getting Started

Follow the steps below to set up and run the application locally.

---

## 📋 Prerequisites

Make sure you have the following installed on your machine:

- **Node.js** (version 25 or higher recommended)
- **npm** (included with Node.js)

Verify installation:

```bash
node -v
npm -v
```

Install modules:

```bash
npm i
```

Run application:

```bash
npm start
```

Open browser on:
http://localhost:8080
